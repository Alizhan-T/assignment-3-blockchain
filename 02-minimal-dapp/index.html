What this dApp does

It uses an injected wallet provider (window.ethereum) and ethers.js v6 to: connect, show account + chainId, and call a read-only function on your contract.

Expected output

Status: Read success ChainId: 31337 Read result: MyToken

Common fixes

• MetaMask not found → install MetaMask extension • ChainId = 1 → switch to Hardhat Local (31337) • Read failed → check contract address / network / ABI
