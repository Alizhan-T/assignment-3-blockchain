Blockchain architecture consists of blocks, transactions, nodes, and a consensus mechanism.  
Each block stores transaction data and is linked to the previous block using cryptographic hashes.

Consensus is the process by which the network agrees on the current state of the blockchain.  
It ensures that all nodes share the same version of the ledger.

Proof of Work (PoW) uses computational power to validate blocks, while Proof of Stake (PoS) relies on validators who stake tokens.  
PoS is more energy efficient than PoW.

In a local Hardhat network, consensus is simulated, allowing instant block creation for development and testing purposes.
